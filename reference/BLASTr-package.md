# BLASTr: Parallel Taxonomic Classification of Metabarcoding Sequences

Seamlessly run 'BLAST' searches within 'R', tailored for the taxonomic
identification of amplicon sequences. This package offers a robust set
of functions designed to efficiently identify and process sequences from
high-throughput metabarcoding and metagenomic experiments, following
best practices for sequence data analysis.
